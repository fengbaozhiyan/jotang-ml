# 一、卷积层为什么比巨大全连接层更适合图像？尝试用全连接层实现猫狗分类 + 对比差距

## 1. 核心原因

1. **局部感受野 + 权值共享（卷积最大优势）**
图像的信息是**局部相关**：识别猫耳朵只需要一小块区域，不需要整张图。
卷积核只看局部；**同一个卷积核在整张图复用一套参数**，参数量大幅下降。
巨大全连接层：把图片展平成一维向量，**每个像素和下一层所有神经元都建立连接**，完全丢失空间位置信息（像素挪一下位置，向量就完全变了），参数量爆炸。
2. **平移不变性**
物体在图片里稍微移动一点，卷积依然能提取到边缘、纹理；全连接层没有这个性质。
3. **保留空间二维结构**
卷积输出还是二维特征图；全连接直接拉成一维，丢失空间结构。

## 2. 两者差距

- **参数量**：MLP 几百万参数，CNN 只有少量参数；MLP 极易过拟合，占用更多内存。
- **性能**：
  - MLP：只能学到像素灰度统计，**不懂边缘、轮廓、局部纹理**。验证集准确率很低，稍微换位置就识别失败。
  - CNN：逐层提取边缘→纹理→局部形状，泛化能力更强。
- **训练难度**：MLP 收敛慢，很容易训练集准确率很高、验证集很差（严重过拟合）。

# 二、卷积层输入通道、输出通道，和卷积核数量关系

公式：`nn.Conv2d(in_channels, out_channels, kernel_size)`

1. **输入通道 in_channels**：输入特征图的通道数。
   - RGB 原图：in_channels=3（R/G/B 三个通道）
   - 上一层卷积输出 16 张特征图，这一层输入通道就是 16
2. **输出通道 out_channels**：**等于卷积核的数量**。
   - `Conv2d(3,16,3)`：一共 **16 个卷积核**。
   - 每个卷积核：形状 `(in_channels, k, k)`，16 个卷积核分别对输入做卷积，得到 16 张特征图，也就是输出通道 = 16。

一句话总结：

> 
> 输出通道 = 卷积核个数；每个卷积核的深度 = 输入通道数。

# 三、padding、stride、pooling 如何改变特征图尺寸，用你网络里一层实际演算

卷积输出尺寸通用公式：

\(H_{out}= \lfloor \frac{H_{in}+2P-K}{S} \rfloor +1\)
\(H_{in}\)：输入高；K：kernel；P：padding；S：stride

你的网络第一层：`conv1, K=3, P=1, stride默认=1`
输入图片：\(128\times128\)

\(H_{out}= \frac{128 + 2\times1 -3}{1}+1 = 128\)
卷积后尺寸不变，再经过 `MaxPool2d(2,2)`
池化公式：

\(H_{out}= \lfloor\frac{H_{in}-K}{S}\rfloor +1\)
池化核 = 2，stride=2

\(H_{out}= \frac{128-2}{2}+1 = 64\)
✅ conv1+pool 后：特征图尺寸：**64×64，通道 16**

### 三个参数作用

1. **Padding 填充**：在图像四周补 0，控制卷积后尺寸缩小速度，**保留边缘信息**。`padding=1`，3×3 卷积，输入输出尺寸不变（same padding）。
2. **Stride 步长**：卷积核滑动间隔。stride>1 会直接下采样，减少特征图尺寸，计算量下降。stride=2 相当于隔一个像素采样。
3. **Pooling 池化**：下采样，压缩宽高，降低计算量；获得一定程度平移不变性；**不引入参数**。代价：丢失部分细节信息。

继续把你完整网络走一遍：

- conv1(3→16,3,pad1) → 128×128 → pool → 64×64 ch16
- conv2(16→32,3,pad1) →64×64 → pool →32×32 ch32
- conv3 (32→64,3,pad1) →32×32 → pool →16×16 ch64
展平：\(64\times16\times16\)，正好对应你 `fc1 = nn.Linear(64 * 16 * 16, 128)`

# 四、为什么越深，特征图宽高变小，通道数变多？

1. **宽高越来越小**：卷积 + 池化不断下采样。底层保存像素细节；高层不需要精细空间分辨率，关注物体整体形状。
2. **通道数越来越多**：
   - 浅层：只提取基础简单特征（边缘、明暗、线条），少量卷积核足够。
   - 深层：要组合基础特征，表达更复杂语义（猫耳朵、眼睛、轮廓）。**每一个输出通道代表一种独立的高级特征检测器**，需要更多卷积核，所以通道数增加。

> 
> 形象理解：
> 低层：几十张简单线条图
> 高层：几十张不同物体部件的语义特征图，空间上压缩，但特征种类变多。

# 五、激活函数 & 损失函数，为什么适合二分类

## 1. 激活函数：ReLU `F.relu`

\(ReLU(x)=max(0,x)\)

- 作用：**引入非线性**。如果没有激活函数，整个网络等价于线性变换，无论多少层都等价单层模型，无法拟合复杂图像分布。
- 优点：
  - 解决 sigmoid 梯度消失；计算速度快；正区间梯度恒定。
- 放在卷积输出之后，用来非线性变换特征。

> 
> 注意：最后一层**没有 ReLU**，直接输出 logits（原始分数）。

## 2. 损失函数：`nn.CrossEntropyLoss()`

适合分类任务，**内部自动做 softmax**：把网络原始输出 logits 转为类别概率。
二分类场景：输出 2 个 logit，代表猫 / 狗得分。
CrossEntropy 衡量预测分布和真实标签分布的差距。

✅ 为什么不用 Sigmoid+BCELoss？
两种都可以做二分类：

- CrossEntropyLoss：多分类通用（2 分类是特例），输入是**两个类别 logits**，代码写法更简洁，数值稳定性更好，你当前网络输出 2 个神经元正好匹配。
- BCELoss：单独做单神经元二分类（输出 1 个概率）。

> 
> 你的网络：输出 2 个神经元，CrossEntropyLoss 是最佳选择。

# 六、为什么增强只给训练集，验证 / 测试集不能原样增强？翻转、裁剪、颜色变化作用

## 核心原则

验证集、测试集用来评估**模型真实泛化性能**，必须模拟**真实世界推理场景**。
训练增强是人为制造更多样本，用来**防止过拟合**；如果验证集也做随机增强：
每次验证时图片随机变，评估指标不稳定，**不能反映模型真实能力**。推理时你不会随机翻转图片，评估集就要保持原图标准变换（只 resize、转 tensor）。

## 三种增强

1. **随机水平翻转 RandomHorizontalFlip (p=0.5)**
   - 帮助：猫狗左右翻转，类别不变。扩充样本，让模型不依赖 “猫脸朝左” 这种偶然特征。
   - 问题：**不能垂直翻转**，现实猫狗不会倒立；有些任务（文字、数字）不能翻转。
2. **RandomCrop 随机裁剪**
   - 帮助：原图放大后随机裁一小块，强迫模型学习物体主体特征，而不是背景。
   - 问题：裁剪不当可能裁掉目标主体，标签失效。
3. **ColorJitter 亮度对比度扰动**
   - 帮助：模拟光照变化，模型不会因为照片亮一点暗一点就认错。
   - 问题：参数太强会破坏图像语义，图片失真，引入错误样本。

> 
> 一句话：训练集增强 = 加噪声扩充样本；val/test 只用基础预处理，保证评价公平。
