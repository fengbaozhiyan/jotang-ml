## 1.为什么不同项目最好使用不同的 Python 虚拟环境？
    
    不同项目依赖的包版本可能冲突。虚拟环境为每个项目单独隔离一套 Python 解释器与第三方库，互不干扰，方便项目依赖管理、复现代码，不会污染全局 Python 环境。

## 2.CPU 和 GPU 各自擅长什么？训练神经网络为什么经常使用 GPU？

    CPU：擅长复杂逻辑分支、串行任务、复杂判断，通用性强。

    GPU：擅长大量简单计算并行执行。
    
    神经网络训练有海量矩阵乘法，属于大量重复简单运算，GPU 上千个小核心可以同时并行计算，速度远高于 CPU。

## 3.CUDA 是什么？它、显卡驱动与 PyTorch 之间大致是什么关系？

    CUDA 是英伟达推出的并行计算平台与编程模型，允许代码直接在 NVIDIA GPU 上运行。

    关系：显卡驱动是底层，负责操作系统和显卡硬件通信；CUDA 构建在驱动之上，提供 GPU 计算 API；PyTorch 内部调用 CUDA 接口，把张量运算下发到 GPU 硬件执行。
