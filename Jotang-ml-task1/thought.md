## 1. 这个任务之中，选择了什么激活函数，为什么选这个？
**基线模型选用 ReLU 激活函数**
公式：$\text{ReLU}(z)=\max(0,z)$
原因：
1. 引入**非线性**。如果没有激活函数，无论叠加多少全连接层，网络整体等价于单层线性变换，**无法拟合月牙这种非线性边界**。
2. 缓解梯度消失：ReLU在正数区域梯度恒为1，相比Tanh、Sigmoid，深层网络不容易出现梯度消失。
3. 计算简单，只做取最大值，训练速度更快。
4. 本实验对照实验额外使用Tanh，用来对比不同非线性带来的收敛差异。

> 缺点：存在神经元死亡（Dead ReLU）问题；但在这个浅层小MLP任务里几乎不会出现。

## 2. 你选择了什么损失函数？为什么？那如果这一题是三分类问题呢？
本任务是**二分类**，选用 `BCEWithLogitsLoss`。
- 输入是网络原始输出 logit（**不提前做sigmoid**），函数内部自带sigmoid运算。
- 数学上等价于 Sigmoid + BCELoss，但是数值稳定性更好，减少浮点数溢出。
- 适合二分类任务，衡量预测概率分布和0/1标签之间的差距。

> 如果改为**三分类问题**：
使用 `CrossEntropyLoss`（交叉熵损失）。
网络输出层输出3个logit，不需要softmax，`CrossEntropyLoss`内部自带softmax，计算多分类交叉熵。标签不再是0/1，取值0、1、2。

## 3. `optimizer.zero_grad()`、`loss.backward()` 和 `optimizer.step()` 分别完成了什么工作？如果不清空梯度会发生什么？
1. **`optimizer.zero_grad()`：梯度清零**
清空上一个batch保存在参数上的梯度。PyTorch中梯度**默认累加**，不是覆盖。
2. **`loss.backward()`：反向传播**
自动微分，利用链式法则，从loss往输入方向求导，计算每一个权重、偏置的梯度 $\frac{\partial L}{\partial W}$，并存到张量`.grad`属性。**只算梯度，不更新权重**。
3. **`optimizer.step()`：参数更新**
优化器读取`.grad`梯度，按照优化算法（Adam）更新权重与偏置，降低损失。

>  如果不清空梯度：
新batch算出的梯度**叠加到老梯度上**，梯度会越来越大，参数更新方向错误，loss震荡、不收敛，模型无法正常学习。

## 4. 更深、更宽的神经网络一定能取得更好的效果吗？模型过于简单或过于复杂分别可能带来什么问题？
**不一定。更深更宽只是增大模型容量，不一定泛化更好。**
- **模型过于简单（太浅、神经元太少，如hidden_dim=16）**：**欠拟合**
模型容量不足，无法捕捉数据里面的非线性规律，**训练集loss高、准确率低**，验证集效果同样差。训练和验证效果差距不大，曲线都上不去。

- **模型过于复杂（很深、很多神经元）**：**过拟合**
容量过大，记忆力太强，不仅学到数据规律，还记住训练集噪声与随机误差。
表现：训练集loss很低、准确率很高；**验证集loss后期上升、准确率下降**。在陌生测试集上效果变差，泛化能力差。

> 核心：我们追求的不是在训练集刷高分，而是**在未见过的数据上有好效果（泛化）**。

## 5. 学习率过大或过小会怎样影响模型训练？你能从 loss 曲线中观察到哪些现象？
- **学习率 lr 过大**
参数更新步长太大，在损失曲面来回跳跃，无法收敛到最低点。
loss曲线现象：loss剧烈震荡，无法持续下降；甚至loss直接爆炸变大，准确率上不去。

- **学习率 lr 过小**
参数每次更新幅度极小，学习非常缓慢。
loss曲线现象：loss缓慢下降，需要极多epoch才会收敛；训练效率很低，若epoch不足则直接欠拟合。

> 合适lr：loss平稳持续下降，后期逐渐平缓收敛。

## 6. 假设还有一个分类问题，但是两个类别的样本数量非常不均衡，训练出来的模型会怎么样？为什么？说明了什么？ 你可以尝试构造一个数据集试试看
### 现象
模型会偏向**数量多的大类**，倾向于把样本预测为大类。整体准确率看起来很高，但少数类识别很差。
例：95个类别0，5个类别1；模型无脑全部预测0，就拿到95%准确率，但是完全识别不出类别1。

### 原因
损失函数是对全部样本求平均，多数类样本贡献的loss占主导。模型只要在多数类上做好，总loss就会很低，不会优先学习少数类特征。

### 说明
**单纯的准确率在不均衡数据集是虚假指标**，不能只用Acc评估；需要看混淆矩阵、召回率、精确率。
解决办法：加权损失、重采样（过采样少数类/欠采样多数类）。

#### 构造不平衡数据集示例代码（基于make_moons）
```python
from sklearn.datasets import make_moons
import numpy as np
# 生成2000样本，然后筛选，制造不平衡：类别0:1900，类别1:100
X,y = make_moons(n_samples=2000,noise=0.2,random_state=42)
idx0 = np.where(y==0)[0][:1900]
idx1 = np.where(y==1)[0][:100]
idx = np.concatenate([idx0,idx1])
X_unbal, y_unbal = X[idx], y[idx]
print("类别0数量",np.sum(y_unbal==0),"类别1数量",np.sum(y_unbal==1))
```

## 7. 如果想要过拟合这个数据集，你会怎么做？为什么？试试看能不能实现吧！（在别的数据集也可以）训练过程和数据呈现和正常训练有何不同？你通过什么判断他过拟合？
### 如何刻意制造过拟合
1. 增大模型容量：加宽隐藏层（hidden_dim=256/512）、增加多层隐藏层；
2. 增加epoch，长时间训练；
3. 去掉任何正则化（无dropout、无权重衰减）；
4. 减少训练样本，只拿少量样本训练，更容易记住。

原理：超大容量模型记忆训练样本，学习样本里的噪声而不是通用规律。

### 训练曲线差异
- 正常收敛：train loss下降、val loss下降，后期平稳，两者差距不大
- 过拟合：**train loss持续降到很低，train acc接近100%；val loss先降后上升，val acc先升后下降**

### 判断过拟合的依据（重点）
1. Loss/Acc曲线：训练集和验证集性能差距持续拉大；验证loss后期上升。
2. 决策边界：边界非常扭曲、细碎，过度贴合训练点，边界出现很多不必要的弯折。
3. 测试集性能：训练集极高准确率，但是测试集明显变差。
